## 📁 建議商品模組資料夾結構

每個商品建議各自建立獨立子資料夾，例如：

```text
2-product-collection/
├── README.md
├── PROD-001-SoulColor/
│   ├── src/                    # 靜態 HTML/CSS/JS 網頁原始碼
│   ├── assets/                 # 視覺圖片、音效與圖標
│   ├── xiaohongshu-listing/    # 小紅書上架素材（封面圖、詳情頁文案、關鍵字）
│   └── README.md               # 該商品的測試連結與交付說明
```

## 🚚 虛擬商品交付與自動發貨流程

1. **買家下單**：買家於小紅書商城購買心理測驗商品。
2. **自動發貨**：自動發貨系統（或小紅書自動回覆機制）發送專屬 H5 網頁連結與兌換卡密。
3. **沉浸體驗**：買家點擊連結進入 GitHub Pages / Vercel 託管之靜態 H5 頁面，輸入卡密進行測驗。
4. **報告卡片與裂變**：測驗完成後生成精美的「性格分析報告卡」，買家長按保存圖片並於小紅書曬單分享，形成二次社交傳播。
