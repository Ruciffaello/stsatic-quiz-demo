# 月兔搗麻糬｜完整結果演算報告（3 食材版）

## 1. 新版遊戲規則

每局選擇 3 次食材，角色固定如下：

1. 第 1 味：**主食材**，決定月餅名稱、核心人格與主要祝福。
2. 第 2、3 味：**副食材**，可彼此重複，也可與主食材相同；它們的祝福以補充語加在主祝福後方。
3. 副食材的選擇順序不影響配方與結果。

## 2. 配方數量

主食材有 10 種。兩個副食材可從 10 種食材中重複選擇，且不計順序：

```text
副食材組合 = C(10 + 2 - 1, 2) = C(11, 2) = 55 種
完整配方   = 10 種主食材 × 55 種副食材組合 = 550 種
```

| 配方分類 | 每個主食材的配方數 | 全部配方數 | 主結果類型 |
| --- | ---: | ---: | --- |
| 兩個副食材皆不同於主食材 | 45 | 450 | 混口味標準結果 |
| 至少一個副食材等於主食材 | 10 | 100 | 純口味核心結果 |
| 其中：主＋主＋主 | 1 | 10 | 完整純口味 |
| **合計** | **55** | **550** | |

## 3. 結算優先順序

```text
完成第三次選料
        │
        ▼
先擲 1% 稀有機率
        ├─ 成功 → 月兔天選・萬福十全糬
        │
        └─ 未成功（99%）
                │
                ▼
       任一副食材是否與主食材相同？
        ├─ 是 → 使用主食材的純口味名稱、核心祝福與寓意
        └─ 否 → 使用主食材的混口味名稱、核心祝福與寓意
                │
                ▼
       將不同於主食材的副食材祝福附加在後方
```

### 副食材祝福規則

| 副食材狀態 | 顯示方式 |
| --- | --- |
| B、C 都不同於主味 A，且 B ≠ C | 主祝福＋B 補充語＋C 補充語 |
| B、B 都不同於主味 A | 主祝福＋B 的加強版補充語 |
| A、B | 純口味主祝福＋B 補充語；A 不重複顯示為副味 |
| A、A | 完整純口味主祝福，不加其他副味語 |

因此「主味重複」不是把其他副味丟掉。例如 `紅豆（主）＋紅豆＋芝麻` 的核心會是純口味「一心紅豆糬」，芝麻仍在後方補充「穩穩向上」。
