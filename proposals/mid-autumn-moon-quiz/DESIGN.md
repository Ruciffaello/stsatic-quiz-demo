# 月兔搗麻糬｜設計規格

## 視覺方向

精緻國風月宮：深紫夜空、暖金月光、深朱紅按鈕與療癒手繪兔子。整體保留留白與層次，不使用過度裝飾的邊框或線條。

## 色彩與字體

| 用途 | 規格 |
| --- | --- |
| 夜空背景 | `#0d0a14`、紫黑放射漸層 |
| 月光與描邊金 | `#ffd27d` |
| 朱紅按鈕 | `#c53535` → `#8c1b20` |
| 結果名稱 | 深朱紅 `#7a2028` |
| 主體字 | Noto Sans TC |
| 標題／結果名 | Noto Serif TC |

## 封面

- 250px 圓形月亮置於中央，採米白至暖金的徑向漸層與微弱呼吸動畫。
- 標題「玉杵輕落・萬願成糬」置於月面中央，使用深朱紅漸層宋體風格。
- 月亮右側為直向三顆星點。
- 說明文字放在月亮下方。
- 兔子使用 `Rabbit holding moon cake_7223575.png` 原圖，160px 高，置於說明文字下方。
- 底部為朱紅主按鈕與「一主二副 · 煉就一顆專屬月餅」註腳。

## 選料頁

- 顯示 10 種食材，採 4＋3＋3 排列。
- 第 1 輪文字為「選主食材」；第 2、3 輪為「選副食材」。
- 食材卡只保留圖示、名稱與代表色點；選取後顯示其簡短寓意。
- 畫面上方以兔子、石臼與麻糬呈現目前混色；開始為白色，之後採已選食材 RGB 平均色。

## 搗製動畫

- 兔子、搗杵、石臼與麻糬使用 CSS 圖形與 1.35 秒循環動畫。
- 搗杵為加寬圓柱，雙手直接抓在杵上並一起移動。
- 兔子在下壓時有輕微彈跳；石臼、麻糬與白色粒子集中於上半部，與兔子距離緊密。
- 麻糬使用白色至混色陰影的徑向漸層，石臼內有壓扁與飛濺粒子效果。

## 結果頁

- 上方為月亮主視覺；「中秋限定」置於月面，結果名稱在月亮中央。
- 月餅以 `gg yolk pastry dessert illustration_7125802.png` 為底圖，Canvas 僅對前方切面內餡套用三種食材混色；外皮、芝麻與蛋黃維持原樣。
- 結果卡與月餅保留適當間距，內容依序為：核心配方、麻糬寓意總結、副效果兩行、中秋祝福。
- 「麻糬寓意」標籤與主結論分行；主結論置中。副效果標籤 14px，結果卡標籤 15px。
- 保存按鈕僅顯示截圖提示，不實作圖片匯出。

## 響應式原則

- 以 430px 內手機 WebView 為主要版型。
- 小於 390px 時縮小結果插圖與字級，但不改變資訊順序。
- 動畫與結果內容允許自然垂直捲動，避免壓縮成難以閱讀的比例。
