## 🔤 2. 字體與排版規範 (Typography)

- **英文字型**：`Plus Jakarta Sans` / `Outfit`
- **中文字型**：`Noto Sans TC` / `PingFang SC` / 系統無襯線字體
- **標題層級**：
  - H1 (首頁大標題)：`24px ~ 28px` / 粗體 700 / 行高 1.3
  - H2 (題目/結果名)：`20px ~ 22px` / 粗體 700 / 行高 1.4
  - Body (正文與選項)：`15px ~ 16px` / 常規 400 ~ 500 / 行高 1.6

---

## ✨ 3. 核心互動與微動畫 (Micro-Interactions)

1. **按鈕點擊反饋**：點擊時輕微縮放 `transform: scale(0.98)` 與發光漸層流動。
2. **選項切換過渡**：平滑淡入淡出 `transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`。
3. **進度條推進**：作答時以彈性曲線平滑增加寬度。
4. **結果揭曉動畫**：結果卡片由下方淡入並帶有專屬光暈浮動特效。

---

## 📸 4. 結果卡片截圖規範 (Result Card Spec for html2canvas)

- **卡片寬高比例**：`4:5` (如 `360px × 450px` 或 `1080px × 1350px`)，完美適配小紅書 / IG 故事尺寸。
- **卡片必須元素**：
  1. 頂部品牌與流水序號 (`OnePage 專屬 ‧ xxx卡` + `NO.2026-xxxx`)
  2. 結果代表圖示 / Emoji / 動態光暈
  3. 稱號大標題 + 3 個性格 HashTags
  4. 深度性格分析解析文案 (約 120 字)
  5. 3 條長條圖指標數據 (例如：洞察力 90%、療癒力 95%)
  6. 幸運金句與底部存圖分享提示
