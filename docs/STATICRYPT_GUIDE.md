# 🔒 StatiCrypt 靜態網頁加密與小紅書卡密保護指南

本文件說明如何利用 **StatiCrypt** 機制為小紅書虛擬商品進行靜態 AES-256 全密文加密防護。

---

## 🛡️ 加密運作原理

1. **為什麼需要全密文加密？**
   - 小紅書虛擬商品（如心理測驗 H5）在買家付款後才發放存取權限。
   - 若直接暴露無加密的 HTML/JS，任何人或爬蟲只要知道網址就能查看測驗內容與題目解答。
   - StatiCrypt 將單一整合後的 HTML、CSS 與 JS 全部壓縮加密成 AES-256 密文字串。

2. **記憶體內解密 (In-Memory Decryption)**：
   - 買家於解密介面輸入卡密 -> 瀏覽器利用 Web Crypto API 於記憶體中解密。
   - 解密成功後直接在同一頁面繪製測驗，無須重新載入或重定向，體驗無縫且防護力最強。

---

## 🔑 小紅書發貨與卡密維護

所有測驗的卡密統一登記於 [`tools/config.js`](file:///D:/專案設計/小紅書心理測驗開發與專案紀錄/tools/config.js)：

| 測驗 ID | 測驗名稱 | 小紅書預設發貨卡密 | 線上存取路徑 |
|---|---|---|---|
| `soul-color` | 尋找你的靈魂氣質色 | `8888` | `/q/soul-color/` |
| `guardian-beast` | 解鎖你的隱藏守護神獸 | `9999` | `/q/guardian-beast/` |

---

## 📝 自動發貨文案模板 (自動回覆 / 虛擬商品發貨)

當小紅書買家完成下單後，系統或客服發送以下內容：

```text

您購買的心理測驗已為您準備就緒！

🔗 測驗網址：https://quiz.yourdomain.com/q/soul-color/

💡 使用說明：
1. 點擊上述網址開啟測驗頁面。
2. 輸入解鎖卡密即可開始作答。
3. 測驗完成後可一鍵保存個人專屬性格分析報告卡！
```
