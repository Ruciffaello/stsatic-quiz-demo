# 🔒 StatiCrypt 靜態網頁加密與卡密保護指南

本文件說明如何利用 **StatiCrypt (AES-256-GCM)** 機制為心理測驗虛擬商品進行靜態全密文加密防護。

---

## 🛡️ 加密運作原理

1. **為什麼需要全密文加密？**
   - 心理測驗 H5 作為虛擬商品在買家付款後才發放存取卡密（支援小紅書、蝦皮、LINE 官方帳號、微信小店、Gumroad 等）。
   - 若直接暴露無加密的 HTML/JS，任何人或爬蟲只要知道網址就能查看測驗內容與題目解答。
   - StatiCrypt 將單一整合後的 HTML、CSS 與 JS 全部壓縮加密成 AES-256-GCM 密文字串。

2. **記憶體內解密 (In-Memory Decryption)**：
   - 買家於解密介面輸入卡密 -> 瀏覽器利用 Web Crypto API 於記憶體中即時解密。
   - 解密成功後透過 DOMParser 直接在同一頁面無縫替換網頁，無須重新載入或跳轉重定向，體驗流暢且防護力最高。

---

## 🔑 卡密維護與路徑對照

所有測驗的卡密統一登記於 [`tools/config.js`](file:///D:/專案設計/小紅書心理測驗開發與專案紀錄/tools/config.js)：

| 測驗 ID | 測驗名稱 | 預設發貨卡密 | 線上存取路徑 |
|---|---|---|---|
| `soul-color` | 尋找你的靈魂氣質色 | `8888` | `/q/soul-color/` |
| `guardian-beast` | 解鎖你的隱藏守護神獸 | `9999` | `/q/guardian-beast/` |
| `love-attachment` | 戀愛依戀類型與契合度診斷 | `7777` | `/q/love-attachment/` |
