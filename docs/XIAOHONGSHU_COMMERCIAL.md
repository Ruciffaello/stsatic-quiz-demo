## 🚚 虛擬商品自動發貨與交付流程

```text
買家小紅書下單 ➔ 系統發送 URL + 卡密 ➔ 買家進入單一網域 H5 ➔ 輸入卡密解鎖 ➔ 完成測驗並生成報告卡片
```

1. **買家下單**：買家於小紅書店鋪購買指定心理測驗商品。
2. **自動發貨**：自動發貨系統（或卡密工具）發送對應測驗路徑與解鎖密碼（例：網址 `/q/soul-color/` + 卡密 `8888`）。
3. **沉浸體驗**：買家開啟連結輸入卡密解鎖，進行流暢的作答體驗。
4. **生成報告卡片**：測驗完成後利用 `html2canvas` 產生精美的「分析報告卡片」。
5. **曬單裂變**：買家長按保存圖片並於小紅書曬單分享（卡片附帶 QR Code 或店鋪搜尋關鍵字），實現二次社交傳播！
