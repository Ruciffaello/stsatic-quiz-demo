# 小紅書心理測驗開發與專案紀錄 (Xiaohongshu Psychological Quiz Development)

本專案旨在利用靜態網頁技術（HTML / CSS / JavaScript）結合互動式心理測驗遊戲，打造適用於**小紅書商城販售的虛擬商品與行銷互動工具**。

---

## 📁 專案架構

本資料夾規劃為兩個核心主資料夾：

```text
小紅書心理測驗開發與專案紀錄/
├── 1-github-pages-verification/   # [1] GitHub Pages 部署與技術驗證
│   ├── README.md                  # GitHub Pages 測試說明與驗證清單
│   └── poc-demo/                  # 可直接部署至 GH-Pages 的 PoC 心理測驗 Demo
└── 2-product-collection/          # [2] 心理測驗商品集與模組化產品庫
    └── README.md                  # 虛擬商品目錄、交付流程與規格說明
```

---

## 🎯 專案目標與定位

1. **靜態 Web 技術 (Static Web Stack)**：
   - 使用輕量純粹的 HTML5, Modern CSS (Flexbox/Grid/Glassmorphism/Animations), Vanilla JS。
   - 零耗伺服器成本，無後端負擔，載入快速。
2. **小紅書虛擬商品與流量轉化**：
   - 透過靜態網頁與互動遊戲提升買家體驗。
   - 提供專屬連結 / 兌換碼 / 掃碼進入，進行心理測驗測驗並產出美觀的「心理特徵報告卡片」。
3. **GitHub Pages 驗證機制**：
   - 在上架商城前，先使用 GitHub Pages 進行免費託管、手機端 Webview 測試、流暢度與跨平台相容性驗證。

---

## 🚀 快速開始

1. 進入 `1-github-pages-verification/poc-demo` 資料夾測試現成的心理測驗 Demo。
2. 將本專案推送到 GitHub 並開啟 **GitHub Pages** 服務，即可取得公開線上網址進行體驗與測試。
